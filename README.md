# ⛅ Weather App – Aplicación del Clima

Aplicación web que permite consultar el clima actual de cualquier ciudad del mundo usando datos en tiempo real desde una API meteorológica.  
Diseñada con una interfaz limpia, moderna y fácil de usar, con resultados rápidos y precisos.

---

## 🌍 Demo
👉 **Deploy:** [(link)](https://weather-app-4gmb.vercel.app/)

---

## ✨ Características principales
- ✔️ Búsqueda por nombre de ciudad  
- ✔️ Datos en tiempo real desde API (temperatura, humedad, sensación térmica, viento, etc.)  
- ✔️ Iconos dinámicos según el clima (soleado, nublado, lluvia, etc.)  
- ✔️ Manejo de errores (ciudad no encontrada, API caída, etc.)  
- ✔️ Diseño responsivo para móvil y escritorio  
- ✔️ Animaciones suaves en la aparición de los datos  
- ✔️ Fondo o estilo que cambia según el clima

## 🎯 Cómo usar
1. Introduce el nombre de la ciudad en el buscador.  
2. Presiona Enter o el botón de búsqueda.  
3. La app mostrará:  
   - Temperatura actual  
   - Estado del clima  
   - Humedad  
   - Viento  
   - Sensación térmica  
   - Icono correspondiente
